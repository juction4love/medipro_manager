१. App Login / OTP

  1. Mobile → OTP → Pharmacy details → Activate.
  2. App Lock PIN optional.

२. Dashboard

  1. Sales/stock summary, alerts, recent activity.

३. Medicine Search

  1. Brand, generic, barcode. Global Search in top bar.

४. Purchase

  1. Batch, expiry, qty, cost, supplier. OCR optional. Confirm → stock.

५. Sales

  1. Cart → payment → Complete Sale → invoice PDF/print.

६. Batch Selection (FEFO)

  1. Multiple batches → Select Batch dialog (expiry order). Auto FEFO available.

७. Barcode Scan

  1. Sales: FEFO auto. Purchase: add line. Camera permission required.

८. Sales Return

  1. Process Return — stock + payment + ledger reverse. No cancel on posted invoice.

९. Stock Adjustment

  1. Expired, Damage, Lost, Physical Count. Reason required.

१०. Reports

  1. Reports tab + Accounting (Day Closing, ledger, receipts).

११. Backup

  1. Settings → password → Create Backup (.medipro encrypted).

१२. Restore

  1. Select file + password. Overwrites data — backup first!

१३. About

  1. Settings → About Us, App Information (version, Device ID).
