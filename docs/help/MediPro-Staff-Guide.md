## Quick reference

| Task | Where in app |
|------|----------------|
| Login / OTP | First launch → Activate MediPro |
| Dashboard | Bottom tab **Dashboard** |
| Medicine search | Sales / Purchase / Inventory / Global Search |
| Purchase | Tab **Purchase** |
| Sale | Tab **Sales** |
| Batch picker | Manual sale (2+ batches) |
| Barcode | Scan icon on Sales / Purchase |
| Return | History / Invoice → **Process Return** |
| Adjustment | Tab **Inventory** |
| Reports | Tab **Reports** + Drawer **Accounting** |
| Backup / Restore | Settings → Backup & Restore |
| Help | Drawer → **Help** |
| About | Settings → About Us |

> **Important:** Posted invoices **cannot be cancelled**. Use **Process Return**.

---

## १. App Login / OTP

1. Activate MediPro → mobile number → OTP verify (Resend available).
2. Pharmacy details → Activate.
3. Optional App Lock PIN.
4. License: Settings → License & Subscription.

---

## २. Dashboard

- Daily summary, recent sales/purchases, stock/expiry alerts.
- Drawer: Accounting, Settings, Help.

---

## ३. Medicine Search

- Brand, generic, composition, barcode in Sales/Purchase/Inventory.
- Global Search (top bar): medicines, invoices.
- Medicine module (Drawer): catalog master.

---

## ४. Purchase

1. Search or barcode scan.
2. Batch, expiry, qty, cost required.
3. Supplier — Create from Purchase screen.
4. OCR bill optional.
5. Confirm → stock updated.

---

## ५. Sales

1. Search or scan → cart → payment → Complete Sale.
2. Credit: select customer. Rx: prescription details.
3. Invoice PDF / print / share.

---

## ६. Batch Selection (FEFO)

- Manual sale + multiple batches → **Select Batch** dialog.
- Sorted by expiry (FEFO). **Auto FEFO** or pick batch.
- Single batch → auto select.

---

## ७. Barcode Scan

- Scan icon → camera permission.
- Sales: FEFO auto (no picker). Purchase: add line.
- 6+ digit codes in search field also work.

---

## ८. Sales Return

- History / Invoice → **Process Return**.
- Reverses stock, payment, ledger + audit.
- **Do not cancel** posted invoices.

---

## ९. Stock Adjustment

- Inventory → batch → Adjust.
- Expired, Damage, **Lost**, Physical Count, etc.
- Reason required.

---

## १०. Reports

- Reports tab: summaries.
- Accounting: receipts, payments, expenses, **Day Closing**.
- Inventory: damage/expiry reports.

---

## ११. Backup

- Settings → Backup & Restore → password → **Create Backup** (`.medipro`).

---

## १२. Restore

- Select `.medipro` + password. **Overwrites current data** — backup first!

---

## १३. About & App Information

- Settings → About Us, App Information (version, Device ID).
